## Run the portfolio locally

This repository contains the portfolio website, built with JavaScript, CSS, and Vite.

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
npm run preview
```

The resume content is maintained in `src/resume-data.js`, site interactions in `src/main.js`, and styling in `src/style.css`. Vercel builds the project with `npm run build` and publishes the generated `dist` directory. Connect this repository to Vercel to enable preview deployments for branches and production deployments from the configured production branch.
