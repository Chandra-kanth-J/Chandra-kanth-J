# Chandrakanth J — Technical Solution Engineer

A responsive portfolio and professional resume site built with JavaScript, CSS, and Vite.

## Run locally

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
npm run preview
```

The site keeps resume content in `src/resume-data.js`, presentation and interactions in `src/main.js`, and styles in `src/style.css`. Vercel can build the project with `npm run build` and publish the generated `dist` directory. Import the GitHub repository into Vercel to enable preview deployments for branches and production deployments from the configured production branch.
